# Design system

Public home (`/`): #000817 background (user update, 2026-09-23). Other Public pages: #1A0101 background, #EDFFFE text, #C8CBCB accent. Editorial scale, open image surfaces, partial frames, thin borders and generous whitespace.
Workspace: #262730 background, #00E622 state accent, compact app launcher and windows. Mobile uses a grid launcher and stacked app panels.
Admin: #F5F4F0 background, #111111 text, #B49345 accent, structured navigation and tables.

No glow. Square controls. Visible keyboard focus and skip link. Reduced motion disables movement. Metadata uses monospace. Portfolio content comes from data; initial site copy/navigation is transitional JSON configuration, not yet CMS-managed.
